## Проектный опыт

### REST API для управления задачами (Todo API) | Индивидуальный проект
Разработка полноценного API с авторизацией и контейнеризацией.
* Проектирование схемы реляционной БД на базе **SQLAlchemy**.
* Реализация системы регистрации и авторизации через **JWT-токены** и хэширование паролей (**Passlib**).
* Настройка маршрутизации и валидации входящих данных с помощью **FastAPI** и **Pydantic**.
* Написание автоматических тестов (**Pytest**) с использованием in-memory базы данных.
* Контейнеризация приложения с помощью **Docker** для унификации процесса развертывания.
* **Стек:** Python, FastAPI, SQLAlchemy, SQLite, Pytest, Docker, JWT.
